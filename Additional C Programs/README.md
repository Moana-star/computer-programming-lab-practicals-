# Additional C Programs

This supplementary collection is placed after Week 15. It is separate from the original weekly practicals.

**Preservation note:** Week 01–Week 15 folders and source files are not modified by this collection.

## Compile and run

1. Open the required `.c` file in VS Code.
2. Run the **Run Current C File** task.
3. Alternatively, compile from the terminal:

   ```powershell
   gcc "path/to/program.c" -o program.exe
   .\program.exe
   ```
