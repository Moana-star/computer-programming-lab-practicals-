# Additional C Programs

Supplementary exercises placed after Week 15. The original Week 01–15 folders and source files are preserved unchanged.

## Compile and run
Open a chosen .c file in VS Code and run the **Run Current C File** task, or use:
`gcc "path/to/program.c" -o program.exe`
`.\program.exe`
