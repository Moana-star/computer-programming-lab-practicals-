# 12(a) — Count lines, words and characters in a text file

**Manual:** Week 12, 12(a). Run the program from this question folder and enter the sample file path.

## Sample 1
**Source file:** `sample-1.c`
**Input filename:** `sample-data/text-1.txt`
**File contents:**
```text
C programming
is fun
```
**Working:** Two newline-terminated lines, four words and 21 characters (spaces and newline characters are counted).
**Expected output:**
```text
Lines = 2
Words = 4
Characters = 21
```

## Sample 2
**Source file:** `sample-2.c`
**Input filename:** `sample-data/text-2.txt`
**File contents:** `Hello world`
**Working:** One line, two words and 11 characters.

```text
Lines = 1

```
