# 12b — Find string length using a pointer

**Manual:** Week 12, 12b

Each sample is a complete, standalone C program.

## Sample 1

**Source file:** `sample-1.c`

**Input**

```text
computer
```

**Working / calculation**

Pointer traverses eight characters.

**Expected output**

```text
Length = 8
```
