# 15(b) — Merge two files into a third file

**Manual:** Week 15, 15(b). The earlier examples concatenate the first file and second file exactly as stored; the program does not add spaces or line breaks.

## Sample 1
**Source program:** `sample-1.c`
**Input files:** `first1.txt` and `second1.txt`; destination `merge1.txt`.
**First file contents:** `Hello`
**Second file contents:** `World`
**Working:** `Hello` + `World` = `HelloWorld`.
**Destination file contents:** `HelloWorld`
