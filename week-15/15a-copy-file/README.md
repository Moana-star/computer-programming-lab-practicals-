# 15(a) — Copy the contents of one file to another

**Manual:** Week 15, 15(a). The program copies every character from the named source file to the destination and reports the number of characters copied.

## Sample 1
**Source program:** `sample-1.c`
**Input file:** `a1.txt`
**Destination file:** `b1.txt`
**Source contents:** `An array is a collection of elements.`
**Calculation:** 37 characters are copied.
**Expected output:** `37 characters copied from 'a1.txt' to 'b1.txt'`
**Destination contents:** `An array is a collection of elements.`

## Sample 2
**Source program:** `sample-2.c`
**Input file:** `a2.txt`
**Destination file:** `b2.txt`
**Source contents:** `C programming`
**Calculation:** 13 characters are copied.
**Expected output:** `13 characters copied from 'a2.txt' to 'b2.txt'`
**Destination contents:** `C programming`

## Sample 3
**Source program:** `sample-3.c`
**Input file:** `a3.txt`
**Destination file:** `b3.txt`
**Source contents:** `File handling in C`
**Calculation:** This text contains 18 characters (including spaces). The earlier sample output recorded 17; that count was an arithmetic error. The correct count and program output are 18.
**Expected output:** `18 characters copied from 'a3.txt' to 'b3.txt'`
**Destination contents:** `File handling in C`
