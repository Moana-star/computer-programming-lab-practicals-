# 15(a) — Copy the contents of one file to another

**Manual:** Week 15, 15(a). Enter the source and destination names when prompted. The destination is created in the current working directory.

## Sample 1

**Source program:** `sample-1.c`
**Input:** `sample-data/source-1.txt` then `copy-1.txt`
**Source file contents:** `An array is a collection of elements.`
**Working:** Every character is read from the source and written to the destination in order.
**Expected output:** `Contents copied from sample-data/source-1.txt to copy-1.txt.`
**Destination file contents:** `An array is a collection of elements.`
