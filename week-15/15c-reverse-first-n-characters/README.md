# 15(c) — Reverse the first n characters in a file

**Manual:** Week 15, 15(c). These are the exact file contents and n values used in our earlier samples. The program displays the reversed characters; it does not alter the original file.

## Sample 1
**Source program:** `sample-1.c`
**Input file:** `reverse1.txt`; n = 4.
**File contents:** `COMPUTER`
**Working:** The first four characters are C O M P. Reversed: P M O C.
**Expected output:** `PMOC`

## Sample 2
**Source program:** `sample-2.c`
**Input file:** `reverse2.txt`; n = 5.
**File contents:** `PROGRAMMING`
**Working:** The first five characters are P R O G R. Reversed: R G O R P.
**Expected output:** `RGORP`

## Sample 3
**Source program:** `sample-3.c`

**File contents:** `COMPUTER SCIENCE`
**Working:** The first eight characters are C O M P U T E R. Reversed: R E T U P M O C.
