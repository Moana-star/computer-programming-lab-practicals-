# 15(c) — Reverse the first n characters in a file

**Manual:** Week 15, 15(c). The program reads the first n characters and displays them in reverse order; it does not change the original file.

## Sample 1

**Source program:** `sample-1.c`
**Input:** `sample-data/reverse-1.txt`, n = 4
**File contents:** `COMPUTER`
**Working:** Reverse the first 4 characters of COMPUTER.
**Expected output:** `Reversed first 4 characters: PMOC`

## Sample 2

**Source program:** `sample-2.c`
**Input:** `sample-data/reverse-2.txt`, n = 5
**File contents:** `PROGRAMMING`
**Working:** Reverse the first 5 characters of PROGRAMMING.
**Expected output:** `Reversed first 5 characters: RGORP`

## Sample 3

**Source program:** `sample-3.c`
**Input:** `sample-data/reverse-3.txt`, n = 8
**File contents:** `COMPUTER SCIENCE`
**Working:** Reverse the first 8 characters of COMPUTER SCIENCE.
**Expected output:** `Reversed first 8 characters: RETUPMOC`
