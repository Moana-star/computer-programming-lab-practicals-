# 15(c) — Reverse the first n characters in a file

**Manual:** Week 15, 15(c). The program displays the reversed first n characters; the original file is unchanged.

## Sample 1
**Source program:** `sample-1.c`
**Input file:** `reverse1.txt`; n = 4.
**File contents:** `COMPUTER`
**Working:** First four characters C O M P; reverse them to P M O C.
**Expected output:** `Reversed first 4 characters: PMOC`

## Sample 2
**Source program:** `sample-2.c`
**Input file:** `reverse2.txt`; n = 5.
**File contents:** `PROGRAMMING`
**Working:** First five characters P R O G R; reverse them to R G O R P.
**Expected output:** `Reversed first 5 characters: RGORP`

## Sample 3
**Source program:** `sample-3.c`
**Input file:** `reverse3.txt`; n = 8.
**File contents:** `COMPUTER SCIENCE`
**Working:** First eight characters C O M P U T E R; reverse them to R E T U P M O C.
**Expected output:** `Reversed first 8 characters: RETUPMOC`
