# 7a — Find largest and smallest numbers in a list

**Manual:** Week 7, 7a

Each sample is a complete, standalone C program.

## Sample 1

**Source file:** `sample-1.c`

**Input**

```text
5
12 4 19 7 2
```

**Working / calculation**

Minimum is 2; maximum is 19.

**Expected output**

```text
Largest = 19
Smallest = 2
```
