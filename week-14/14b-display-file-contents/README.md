# 14(b) — Display the contents of a file

**Manual:** Week 14, 14(b). Enter the sample filename when the program asks for it.

## Sample 1
**Source program:** `sample-1.c`
**Input filename:** `sample1.txt`
**File contents:** `this is my first program`
**Expected output:**
```text
File contents:
this is my first program
```

## Sample 2
