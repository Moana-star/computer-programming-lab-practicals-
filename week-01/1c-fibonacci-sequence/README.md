# 1(c) — Generate the first n terms of the Fibonacci sequence

**Manual:** Week 01, 1(c). These are the exact three sample runs from our earlier answer.

## Sample 1
**Source file:** `sample-1.c`
**Input:** `5`
**Working:** Start with 0 and 1. Then 0+1=1, 1+1=2, and 1+2=3.
**Expected output:**
```text
Enter the value of n: 5
Fibonacci sequence for the first 5 terms:
0 1 1 2 3
```
