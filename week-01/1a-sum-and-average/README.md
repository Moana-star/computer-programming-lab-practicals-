# 1(a) — Sum and average of three numbers

**Manual:** Week 01, 1(a)

Each sample is a complete, standalone C program. Compile and run one sample at a time.

## Sample 1

**Source file:** `sample-1.c`

**Input**

```text
12 18 30
```

**Working**

Working: 12 + 18 + 30 = 60; average = 60 / 3 = 20.00.

**Expected output**

```text
Sum = 60\nAverage = 20.00
```
