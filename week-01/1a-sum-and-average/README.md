# 1(a) — Sum and average of three numbers

**Manual:** Week 01, 1(a)

Each sample is a complete, standalone C program.

## Sample 1
**Source file:** `sample-1.c`
**Input:** `12 18 30`
**Working:** 12 + 18 + 30 = 60; average = 60 / 3 = 20.00.
**Expected output:**
```text
Sum = 60
Average = 20.00
```
