# 4(a) — Find the roots of a quadratic equation

**Manual:** Week 04, 4(a). These are the exact three samples previously worked out.

## Sample 1
**Source file:** `sample-1.c`
**Input:** `1 -5 6`
**Calculation:** D = b² − 4ac = (−5)² − 4(1)(6) = 25 − 24 = 1. Roots = (5 ± 1)/2.
**Expected output:**
```text
Root 1 = 3.00
Root 2 = 2.00
```

## Sample 2
**Source file:** `sample-2.c`
**Input:** `1 -4 4`
**Calculation:** D = (−4)² − 4(1)(4) = 16 − 16 = 0. Both roots = 4/2 = 2.
**Expected output:**
```text
Both roots are equal = 2.00
```

## Sample 3
**Source file:** `sample-3.c`
**Input:** `1 2 5`
**Calculation:** D = 2² − 4(1)(5) = 4 − 20 = −16. Real part = −2/2 = −1; imaginary part = √16/2 = 2.
**Expected output:**
```text
Root 1 = -1.00 + 2.00i
Root 2 = -1.00 - 2.00i
```
