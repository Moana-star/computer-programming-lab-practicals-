# 5a — Factorial using a non-recursive function

**Manual:** Week 5, 5a

Each sample is a complete, standalone C program.

## Sample 1

**Source file:** `sample-1.c`

**Input**

```text
5
```

**Working / calculation**

**Expected output**

```text
Factorial = 120
```
