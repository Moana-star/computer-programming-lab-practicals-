# 13a — Display array elements using calloc()

**Manual:** Week 13, 13a

Each sample is a complete, standalone C program.

## Sample 1

**Source file:** `sample-1.c`

**Input**

```text
5
1 2 3 4 5
```

**Working / calculation**

Display the five values stored in the allocated array.

**Expected output**

```text
Array elements: 1 2 3 4 5
```
